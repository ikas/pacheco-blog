# [henriquepacheco.com](https://henriquepacheco.com)

Personal website and blog of [@ikas](https://github.com/ikas), built with [Astro](https://astro.build).

Requires Node.js >= 22.12 (see `engines` in `package.json`). Run the commands below from the repo root.

## Development

```sh
npm ci
npm run dev
```

The dev server runs on http://localhost:4321.

## Build

```sh
npm run build
```

This writes the static site to `dist/`.
